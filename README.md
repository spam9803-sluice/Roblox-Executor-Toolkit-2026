## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors bundled together with a universal loader called xcutorsLoader. It provides a single interface to install, manage, and launch multiple executor tools on Windows.

### Which executors are included in the collection?

The collection includes four popular executors: Volt, Synapse Z, Potassium, and Wave. Each can be installed and launched individually through the universal xcutorsLoader interface.

### Is XCutors free to use?

Yes, XCutors and the universal loader are completely free to download and use. All included executors are sourced from their respective free distribution channels.

### What operating systems are supported?

XCutors is designed exclusively for Windows. It supports Windows 10 (version 1903 and later) and Windows 11. macOS and Linux are not currently supported.

### How do I update the executors?

The xcutorsLoader includes a built-in auto-update feature. When you select an executor, it will automatically check for and download the latest version. You can also manually trigger an update from the loader settings.

### Can I add my own custom scripts?

Absolutely. You can place .lua or .luau script files into the designated scripts folder, or use the built-in script editor to write and save new scripts directly. The script hub also allows importing scripts from URLs.

### Is it safe to download from this repository?

Always ensure you download XCutors only from this official GitHub repository. We do not distribute through third-party sites. We recommend scanning any downloaded files with your anticomponent software before running them.

### What Lua version do the executors support?

All included executors support Luau, which is Roblox's modified version of Lua 5.1. This includes support for modern Luau features such as type annotations, string interpolation, and generalized iteration.

### Why does my anticomponent flag the executor files?

Some anticomponent programs may flag script executors as potentially unwanted programs (PUPs) due to their memory-injection behavior. This is a common false positive for this category of software. You may need to add an exclusion in your anticomponent settings.

### How do I report bugs or request features?

Please open an issue on the GitHub repository's Issues page. Provide as much detail as possible including the executor name, steps to reproduce, your Windows version, and any error messages you encounter.
